# SO-101 dataset viewer

Standalone Streamlit viewer for `kdaterao/so101_spread73_v3_unified`.
The page shows all source episode choices and top/wrist videos with revised
captions that update at subtask boundaries. Saved SAM masks and grounding dots
are rendered into preview videos. No GPU, inference models or robot101 checkout
is required.

## Run locally

Use Python 3.12:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Optional dataset override:

```bash
streamlit run app.py -- --repo-id kdaterao/so101_spread73_v3_unified
```

To inspect an existing local combined folder, use `-- --root /path/to/dataset`.
No videos, model weights, dataset outputs or tokens belong in this repository.

## Deploy on Streamlit Community Cloud

1. Connect this GitHub repository in Streamlit Community Cloud.
2. Select branch `main` and entrypoint `app.py`.
3. Select Python **3.12** in Advanced settings.
4. For a private dataset, add `HF_TOKEN` with read access to Secrets. Optionally
   set `HF_DATASET_REPO` to choose another combined dataset. See
   `.streamlit/secrets.toml.example` for the format.
5. Deploy.

Public datasets do not require a token. The host downloads the joined index once
and retrieves camera files/masks for the selected episode on demand. First
playback takes CPU time to render; previews are cached. Full input manifests and
relative worker paths are supported, including lightweight combined datasets.

The two camera players are independent. Autoplay is muted. Browser policy may
require clicking Play. Uploaded dataset videos are never changed by the viewer.
Episode labels and masks may require human review; the app does not infer or
validate robot actions.

## Data format

Expected root artifacts are `subtasks.jsonl`, `manifest.json` and the
`artifacts/inputNN/` worker layout generated by `robot101.data.combine_datasets`.
Rows identify the source dataset revision/episode, annotation node bounds,
revised captions and linked grounding metadata. Raw gripper splits do not replace
the caption boundaries used during playback.
